# Heimdall EMS Portal — Blue Landing Page Concept

A new, responsive front-end concept for Heimdall, presented as an EMS portal similar in broad purpose to emergency medical services providers. It is an independent student design concept and is not affiliated with Netcare 911.

## Features
- Blue-gradient landing page and navigation: Home, About, Johannesburg Map, Contact
- Role selection for Hospital Administrator and Ambulance Driver
- Different demo workspace descriptions for each role
- Embedded OpenStreetMap view centered on Johannesburg
- External Google Maps shortcut
- Contact form preview
- Responsive mobile layout

## Important limitations
This is a static front-end demo. Role selection does not authenticate users. It does not display live ambulances, patients, hospital capacity, dispatch information or live routes. Contact form submissions are not sent or stored. Do not use for real emergency operations or enter sensitive data.

## Publish to GitHub Pages
1. Extract this ZIP.
2. Upload `index.html` to your GitHub repository (replace the earlier `index.html`).
3. Commit the change to `main`.
4. Open Settings → Pages and confirm branch `main`, folder `/(root)`.
5. Wait for deployment; open the published URL.

The embedded OpenStreetMap map requires an internet connection.
