# 🏥 Hospital Facilities Website

A responsive hospital facilities webpage designed to showcase healthcare services and medical departments in a clean, professional, and user-friendly layout.

## 📌 About the Project

This project provides visitors with an overview of hospital facilities, helping patients and their families find information about available healthcare services.

## ✨ Features

- 🚑 Emergency and Trauma Services
- 🏥 Outpatient Services
- 🩺 Intensive Care Unit (ICU)
- 👶 Maternity and Neonatal Care
- 🔬 Laboratory Services
- 🩻 Radiology and Medical Imaging
- 💊 Hospital Pharmacy
- 🛏️ Inpatient Wards
- 🚐 Emergency Medical Services (EMS)
- 📱 Responsive design for mobile, tablet, and desktop
- 🎨 Modern facility cards with hover effects
- 📞 Emergency contact section

## 🛠️ Technologies Used

- HTML5 — webpage structure
- CSS3 — styling, layout, animations, and responsiveness
- JavaScript — can be added for interactive functionality

## 📱 Responsive Design

The webpage adjusts its layout to different screen sizes, providing a consistent browsing experience on computers, tablets, and smartphones.

## 🎯 Project Objectives

- Present hospital facilities clearly.
- Improve access to healthcare service information.
- Make emergency contact information easy to locate.
- Create an accessible and user-friendly healthcare website.

## 🔒 Important Notice

This project is a website template. Hospital facilities, emergency numbers, and medical service information must be verified before the website is used publicly.

The website does not currently provide live ambulance dispatch, appointment booking, or emergency response functionality.
